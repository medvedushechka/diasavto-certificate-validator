# ДиасАвто+ — интерфейс

Локальный React + TypeScript + Vite для распознавания масок HI-LEX из сертификатов PDF/DOCX/TXT, проверки введённого артикула и экспорта масок в CSV.

Для Windows используйте **setup.bat** и **start.bat** из корня репозитория. Инструкция по установке и запуску — в [корневом README](../README.md).

Интерфейс обращается к локальному FastAPI через прокси Vite: `/api` → `http://127.0.0.1:8000`. Облачные сервисы и вход не используются.
