# Генерация артикулов из сертификата

## Подтверждённое требование

Каталог товаров не требуется. Система извлекает маски из сертификата и перечисляет **все теоретические сочетания**. Наличие товара в реальном каталоге не проверяется.

## Текущая реализация

- PDF с текстовым слоем, DOCX, TXT; OCR не используется.
- Утверждённые префиксы HI-LEX, четыре символа по алфавиту `0-9A-Z`.
- Ленивый генератор, без списка всех комбинаций в памяти.
- ZIP-архив из CSV-файлов с манифестом и количеством строк.
- Отказ для неизвестных масок. Расширение под других производителей предусмотрено через класс `MaskRule`, но ещё не оформлено как согласованный реестр правил.

## Локальная проверка

```powershell
cd backend
python -m pip install -e ".[dev]"
python -m pytest tests -q
python -m diasavto_validator path\to\certificate.pdf path\to\articles.zip
```

На уровне API доступен защищённый маршрут `POST /api/generation/plan` (multipart-поле `certificate`), который возвращает число масок и ожидаемое число артикулов, но не генерирует архив в рамках HTTP-запроса.

## Ограничения и открытые работы

- При 38 масках формируется 63 825 408 строк. Для полного процесса нужна фоновая обработка с контролем дискового пространства, времени, прогресса, отмены и доступов.
- Vercel Function не подходит для длительной генерации такого объёма. Нужен отдельный worker и приватное файловое хранилище.
- Сейчас рабочий веб-интерфейс всё ещё показывает прежнюю проверку каталога. Его нужно перевести на сценарий «сертификат → план → архив».
- Требуется подтвердить требуемый формат конечного файла (CSV/ZIP предложен как безопасное техническое решение).
- Для новых производителей понадобится отдельный конфиг и проверка пересечений масок; не принимать новые правила от LLM автоматически.
- Переход к новому сценарию нельзя считать завершённым, пока не пройдены CI, интеграционные и нагрузочные испытания.

## Контроль полноты

Для HI-LEX: 36^4 = 1 679 616 артикулов для одной маски, 38 × 36^4 = 63 825 408 для полного перечня. Для каждого успешно записанного архива манифест должен содержать `total == expected`.
