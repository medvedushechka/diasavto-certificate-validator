# Безопасность

## Работа с данными

- Используйте только синтетические данные для разработки и демонстрации.
- Не размещайте реальные документы, каталоги и персональные данные в Git.
- Храните секреты в переменных окружения, не в исходном коде.
- Проверяйте тип, размер и содержимое загружаемых файлов до обработки.
- Не записывайте содержимое входных документов в системные логи.
- Перед публикацией репозитория проверьте все коммиты на случайно добавленные секреты.

## Сообщение об уязвимостях

Не публикуйте подробности потенциальных уязвимостей в открытых Issues. Сообщите владельцу репозитория приватным способом.
