# diasavto-certificate-validator

Приложение для проверки артикулов по маскам сертификатов и подготовки отчёта о соответствии.

## Задача

Сопоставлять позиции каталога с правилами сертификата с учётом производителя, товарной группы и полного совпадения артикула с маской. Отдельно фиксировать отклонённые позиции и причины исключения.

## Статус

Проект находится на этапе проектирования. Реальная база данных компании не используется. Для разработки и тестирования предусмотрены только синтетические примеры.

## Безопасность

Не публикуйте в репозитории реальные каталоги, сертификаты с закрытой информацией, персональные данные и секреты. Перед переводом репозитория в публичный режим требуется проверка содержимого и истории коммитов.
