# ДиасАвто+ — проверка сертификатов HI-LEX

Локальное приложение для распознавания масок артикулов из сертификатов HI-LEX CORPORATION (тросы стояночного тормоза). Работает на компьютере без регистрации, паролей, Supabase, Vercel и других облачных сервисов.

## Быстрый запуск на Windows

### Что нужно установить заранее

- **Python 3.11 или новее** — https://www.python.org/downloads/ (при установке Windows отметьте **Add Python to PATH**).
- **Node.js 22 или новее (LTS) с npm** — https://nodejs.org/.

После установки Python и Node.js откройте новый терминал и при необходимости проверьте:

```bat
python --version
node --version
npm --version
```

### Первый запуск

1. Откройте репозиторий: https://github.com/medvedushechka/diasavto-certificate-validator
2. Нажмите **Code → Download ZIP** и распакуйте архив. Либо клонируйте через `git clone`.
3. В распакованной папке дважды нажмите **setup.bat**. Скрипт:
   - создаёт изолированное Python-окружение `.venv`;
   - устанавливает Python-зависимости backend и тестовые инструменты;
   - устанавливает npm-зависимости frontend;
   - собирает frontend и запускает автоматические Python-тесты.
4. Дождитесь сообщения **SUCCESS. Now run start.bat**. При ошибке окно останется открытым с диагностикой — не переходите к следующему шагу.
5. Дважды нажмите **start.bat**. Он запустит два локальных сервера и откроет страницу в браузере.

**Адрес приложения:** http://127.0.0.1:5173/

При последующих запусках достаточно **start.bat**. Повторно выполнять `setup.bat` нужно только после обновления зависимостей или переустановки проекта.

Для установки зависимостей требуется интернет. Обработка сертификатов выполняется локально; передавать документы в облако не нужно.

### Как остановить

Закройте два открытых окна серверов **DiasAvto API** и **DiasAvto Frontend** или нажмите **Ctrl+C** в каждом.

## Как пользоваться

1. Откройте приложение в браузере.
2. Перетащите сертификат в область загрузки или нажмите **Выбрать файл**.
3. Нажмите **Распознать маски**. Появятся найденные в сертификате маски HI-LEX.
4. Нажмите **Скачать список масок (CSV)** для экспорта.
5. Для проверки конкретного артикула введите его в поле **Проверить артикул** и нажмите кнопку проверки.

Например, маска `4VB****` покрывает артикул `4VB12A9`: первые три символа фиксированы, остальные четыре — латинские буквы A–Z или цифры 0–9. Проверка производится по маскам **загруженного сертификата**, а не только по общему перечню.

В карточке HI-LEX можно навести курсор или нажать на число утверждённых масок, чтобы увидеть полный список из **38** разрешённых масок.

## Поддерживаемые документы и ограничения

| Формат | Ограничения |
|---|---|
| PDF | До 2 МБ, до 30 страниц, необходим текстовый слой |
| DOCX | До 1 МБ |
| TXT | До 1 МБ, UTF-8 |

- OCR для PDF-сканов не реализован.
- Неизвестные или неутверждённые маски отклоняются с сообщением об ошибке.
- Найденные маски сортируются по первым трём символам, повторы удаляются.
- Миллионы возможных комбинаций артикулов **не генерируются**.
- Каталог товаров не требуется. Совпадение с маской не доказывает существование товара в каталоге производителя.
- На данный момент реализованы правила только HI-LEX.

## Проверка и ручной запуск (для разработчиков)

После успешного `setup.bat` из корня репозитория можно запустить тесты отдельно:

```bat
set "PYTHONPATH=%CD%\backend;%CD%\backend\src"
.venv\Scripts\python.exe -m pytest backend/tests -q
```

Проверка качества Python:

```bat
.venv\Scripts\python.exe -m ruff check backend
```

Сборка frontend:

```bat
cd frontend
npm run build
```

При ручном запуске backend (из корня проекта):

```bat
cd backend
..\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

В другом терминале:

```bat
cd frontend
npm run dev
```

- Frontend: http://127.0.0.1:5173/
- Проверка API: http://127.0.0.1:8000/api/health (ожидаемый ответ `{"status":"ok"}`).
- Vite перенаправляет запросы `/api` на локальный backend.

## Если приложение не запускается

- **Не найден Python или npm:** установите указанные выше версии и повторно откройте терминал.
- **Ошибка в setup.bat:** прочитайте сообщение перед `ERROR: Setup or tests failed`. Пока установка не завершилась успешно, `start.bat` запускать не нужно.
- **Страница не открывается:** убедитесь, что оба серверных окна продолжают работать, затем откройте http://127.0.0.1:5173/ вручную.
- **Ошибка подключения к API:** проверьте http://127.0.0.1:8000/api/health. Если он недоступен, проверьте окно **DiasAvto API**.
- **Порт 8000 или 5173 занят:** завершите другой процесс, использующий этот порт, и повторите запуск.
- **Скан PDF не распознаётся:** необходим PDF с текстовым слоем; OCR в приложении нет.
