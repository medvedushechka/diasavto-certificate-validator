# ДиасАвто+ — проверка сертификатов HI-LEX

Локальное приложение для распознавания масок из сертификатов PDF, DOCX и TXT, проверки артикула и выгрузки CSV. Без регистрации и облачных сервисов.

## Запуск (Windows)

1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.
2. Запустите **setup.bat** — он установит зависимости, соберёт проект и проверит тесты. При первом запуске нужен интернет.
3. Запустите **start.bat** — он запустит приложение и откроет браузер.

**Адрес:** http://127.0.0.1:5173/

Для запуска необходимы установленные **Python 3.11+** и **Node.js 22+**. Повторно запускать `setup.bat` не нужно, если зависимости не менялись.

Чтобы остановить приложение, закройте два открывшихся окна серверов.

## Использование

Загрузите сертификат → нажмите **«Распознать маски»** → скачайте CSV или проверьте артикул. Поддерживаются PDF с текстовым слоем (до 2 МБ, 30 страниц), DOCX и TXT (до 1 МБ). OCR не поддерживается.

## Проверка

`setup.bat` автоматически выполняет сборку frontend и тесты backend. Если проверка не пройдёт, он покажет ошибку.
