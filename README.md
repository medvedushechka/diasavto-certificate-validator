# ДиасАвто+ — локальная проверка сертификатов HI-LEX

Проект запускается **на компьютере**, без аккаунтов, облачных сервисов и авторизации.

## Быстрый запуск (Windows)

Нужны установленные **Python 3.11 или новее** и **Node.js 22 или новее** (с npm).

1. Скачайте репозиторий через **Code → Download ZIP**, распакуйте в обычную папку.
2. Запустите **setup.bat** один раз. Он создаст виртуальное окружение Python, установит зависимости backend и frontend и проверит сборку.
3. Запустите **start.bat**. Откроются два окна серверов и браузер по адресу **http://127.0.0.1:5173/**.
4. Чтобы остановить приложение, закройте два окна серверов или нажмите Ctrl+C в каждом.

Интернет нужен только при первой установке зависимостей. Для обработки файлов не требуется доступ к Supabase, Vercel или GitHub.

## Что делает приложение

Загружает сертификат HI-LEX (PDF с текстовым слоем до 2 МБ / 30 страниц, DOCX и TXT до 1 МБ), извлекает **только разрешённые маски** из списка 38, удаляет повторы и сортирует их. Показывает результат и позволяет скачать CSV со списком масок. Дополнительно проверяет **введённый вручную** артикул по маскам загруженного сертификата.

**Все теоретические артикулы не генерируются**, каталог не требуется. OCR для сканов не поддерживается.

## Технические детали

- Backend: FastAPI, Python, адрес http://127.0.0.1:8000/api/health
- Frontend: React, TypeScript, Vite, адрес http://127.0.0.1:5173/
- Frontend обращается к локальному backend через Vite proxy /api.
- Исходные файлы сертификатов обрабатываются локально, в облако не отправляются.

## Проверка разработчиком

```bat
.venv\Scripts\python.exe -m pytest backend/tests -q
cd frontend
npm run build
```

Репозиторий не содержит зависимости: они устанавливаются через setup.bat. Для тестов Python используйте `python -m pip install -e "./backend[dev]"` в активированном окружении.

## Ограничения

Соответствие маске не доказывает наличие артикула в каталоге производителя. Не загружайте в публичные репозитории конфиденциальные сертификаты или личные данные.
